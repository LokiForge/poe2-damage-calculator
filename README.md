# POE2伤害计算器

[打开网站](https://lokiforge.github.io/poe2-damage-calculator/)

全角色通用的直接命中伤害计算器，无需职业、等级、技能选择或登录。

## 输入与计算

界面采用浅灰背景、白色面板和蓝色操作重点。默认只显示基础输入和紧凑的乘区合计列表，点击区间展开多条明细；说明与历史默认折叠。点击“查看计算结果”后进入伤害结果和天赋建议页，可返回修改；刷新始终回到输入页，已保存数据保持不变。各区间 +1 收益在结果页按需展开。

顶部同一框输入技能原始平均伤害和原始攻速。原始攻速需包含技能自身攻速系数，尚未叠加下方攻速 increased。

附加基础伤害、Gain、伤害 inc、攻速增加、暴击率增加、暴击伤害加成增加分别使用独立框，支持多条来源输入与相加。附加伤害需预先折算技能伤害效用。每个 More 效果单独一框：同一效果的可叠加条目相加，各个独立效果相乘。不同来源的独立 More 不应放在同一框。

- 基础池 = 技能原始伤害 + 附加基础伤害合计。
- Gain 后基础池 = 基础池 × (1 + Gain 合计 / 100)。
- 非暴击伤害 = Gain 后基础池 × (1 + inc 合计 / 100) × ∏(1 + 各 More 框合计 / 100)。
- 最终攻速 = 原始攻速 × (1 + 攻速增加合计 / 100)。
- 最终暴击率 = min(100%, 基础暴击率 × (1 + 暴击率增加合计 / 100))。
- 最终暴击伤害加成 = 基础暴击伤害加成 × (1 + 加成增加合计 / 100)。
- 平均伤害 = 非暴击伤害 × (1 + 最终暴击率 / 100 × 最终暴击伤害加成 / 100)。
- DPS = 平均伤害 × 最终攻速。

## Gain 的简化边界

真实 Gain 在增伤前计算，同阶段不递归；额外伤害仅受最终类型的修饰。技能内置 Gain 和其他来源分阶段。本工具按用户要求不增加伤害类型选择，假定所有 Gain 属于同阶段、基于同一份基础伤害，且原伤害和额外伤害适用同一套增伤。所以 20% + 30% Gain 为 ×1.5，而不是 ×1.56。

来源：[游戏说明](https://poe2db.tw/us/Damage_Gained_as_extra_X)、[计算顺序](https://www.poe2wiki.net/wiki/Damage_conversion)、[暴击说明](https://poe2db.tw/Critical_Damage_Bonus)。

敌人使用零抗性、零护甲减伤基准，每次攻击按命中一次计算。不模拟持续伤害、转换链、特殊暴击机制、独立攻速 more、行动速度和冷却。

## 天赋小点比较

核对日期：2026-09-16。采用 GGG 最新公开导出 [0.5.2](https://github.com/grindinggear/poe2-skilltree-export/releases/tag/0.5.2) 中的普通小点：

| 方向 | 默认增量 | 节点 ID |
| --- | --- | --- |
| 伤害 inc | 10% increased Damage | 2200 |
| 攻速 | 3% increased Attack Speed | 97 |
| 暴击率 | 10% increased Critical Hit Chance | 4157 |
| 暴击伤害加成 | 15% increased Critical Damage Bonus | 535 |

节点名称与原文收录在 `passive-sources.json`，数据来自官方 `data.json`。这些值是具体普通小点的示例，并非所有同类节点的统一值；界面允许修改。

分别单独投入一个小点，按新增 DPS 排序。最高收益（含并列）为绿色；低于最高收益一半为红色；其他为中性。所有选项都无增益时不作绿色推荐。不计走路点、天赋位置和资源消耗。每个乘区仍显示 +1 点或 +1 个百分点的边际收益。

## 本地保存

当前配置及最近 50 条历史保存在浏览器 localStorage 的 v2 键。首次使用自动迁移 v1，保留旧键。旧版最终攻速和最终暴击率暂作基础值，暴击伤害以 100% 基础拆分，保留旧 DPS，并提醒用户核对后再录入新的 increased。

配置不上传服务器。不同设备不自动同步，清除站点数据会删除记录。不保证断网加载。

## 开发与发布

Node.js 20+，无构建步骤。`npm test` 运行计算测试；`npm start` 启动静态服务器。GitHub Pages 从 main 分支根目录发布。更新资源时同步修改 HTML 的 JS/CSS 版本参数，以及 app.js 的 calculator.js 导入版本，避免旧缓存混用。
