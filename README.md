# POE2伤害计算器

全角色通用的静态命中伤害计算器。无需职业、等级、技能选择或登录。

- 输入技能平均基础伤害、已折算效用的附加伤害、总 inc、独立 more/less、最终暴击参数、有效命中频率。
- 实时显示非暴击伤害、含暴击平均伤害、DPS，以及各项 +1 点或 +1 个百分点后的边际收益。
- 单独比较已有 more 提高一个百分点和新增独立 1% more。
- localStorage 自动保存当前配置，可保存、载入、删除最近 50 条历史结果。

## 计算口径

DPS = (基础 + 附加) × (1 + inc/100) × ∏(1 + more/100) × (1 + 最终暴击率/100 × 最终暴击伤害加成/100) × 每秒有效命中次数。

敌人基准为零抗性、零护甲减伤、承受伤害倍率 1。这是比较基准，不代表实际敌人。只适用于同一组修饰生效的直接命中，不模拟持续伤害、异常状态、伤害转化和技能特殊机制。基础伤害应使用未包含后续增伤的值，避免重复计算。暴击率封顶 100%；暴击伤害加成 100% 表示暴击为非暴击的 2 倍。

规则参考：[修饰词](https://www.poe2wiki.net/wiki/Modifier)、[暴击](https://www.poe2wiki.net/wiki/Critical_hit)。

## 本地开发

Node.js 20+，无需构建。`npm test` 运行计算测试；`npm start` 启动静态服务器。

GitHub Pages 从 main 分支根目录发布。所有输入和结果仅存储于当前浏览器的 localStorage，不上传服务器。清除站点数据、切换浏览器或设备不会保留记录。静态文件更新不影响同源存储；不提供断网离线加载保证。
